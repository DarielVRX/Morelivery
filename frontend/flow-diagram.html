3 Roles de Usuario

  • Customer — busca, ordena, rastrea
  • Restaurant — gestiona menú y pedidos
  • Driver — acepta ofertas, navega, entrega
  • Admin — panel de administración

Hooks Críticos

  • useRealtimeOrders — SSE + reconexión
  • useOrderManager — estado de órdenes
  • useDriverLocation — GPS + API sync
  • useNavFeatures — voz + wake lock

Patrón registerRef Bus

  • DriverHome owna SSE y expone callbacks
  • DriverOrders y AlertsPanel suscriben
  • Evita múltiples conexiones SSE
  • Sin prop drilling ni re-renders extra
